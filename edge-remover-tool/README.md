# Edge 완전 삭제 도구 (Windows 11)

마이크로소프트는 Edge를 "공식적으로" 완전히 제거하는 기능을 제공하지 않습니다. 이 도구는 가능한 한 깔끔하게 제거하고, 자동 재설치를 최대한 막아주는 최선의(best-effort) 도구입니다. **100% 영구 삭제를 보장하지는 않습니다** — 큰 폭의 Windows 기능 업데이트가 Edge를 다시 설치해버리는 경우가 가끔 있습니다. 그럴 땐 이 스크립트를 다시 실행하면 됩니다.

## 시작하기 전에 꼭 확인하세요

- **다른 브라우저를 먼저 설치하세요.** (Chrome, Firefox 등) Edge를 지우기 전에 기본 브라우저로 지정해두는 걸 권장합니다.
- **WebView2 런타임은 삭제하지 않습니다.** 카카오톡, 디스코드, 일부 게임 런처 등 많은 프로그램이 내부적으로 이 구성요소를 사용하기 때문에, 같이 지우면 그 프로그램들이 실행이 안 될 수 있습니다.
- 관리자 권한이 필요합니다.

## 이 도구가 하는 일

1. Edge 및 Edge 업데이트 관련 프로세스 종료
2. Edge 자동 업데이트 서비스(`edgeupdate`, `edgeupdatem`) 비활성화
3. Edge 자동 업데이트 예약 작업 비활성화
4. 레지스트리 정책으로 Edge 자동 재설치 차단
5. Edge 자체 제거 프로그램(`setup.exe --uninstall`) 실행
6. 남은 설치 폴더 및 바로가기 정리

## 사용 방법

1. `Run-As-Admin.bat`을 더블클릭합니다
2. UAC(사용자 계정 컨트롤) 창이 뜨면 **예**를 클릭합니다
3. 파란 PowerShell 창에 진행 상황이 출력됩니다. 끝날 때까지 기다립니다
4. 완료되면 창을 닫아도 됩니다

## 되돌리고 싶다면

Edge를 다시 설치하고 싶어지면, 마이크로소프트 공식 사이트(microsoft.com/edge)에서 새로 다운로드하거나, `winget install Microsoft.Edge` 명령으로 다시 설치할 수 있습니다. 이 도구가 막아놓은 자동 업데이트 정책은 레지스트리 경로 `HKLM\SOFTWARE\Policies\Microsoft\EdgeUpdate`에서 직접 지우면 해제됩니다.
