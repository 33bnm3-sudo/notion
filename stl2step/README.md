# STL → STEP 변환기

FreeCAD 창을 띄우지 않고, STL 파일을 끌어다 놓기만 하면 STEP 파일로 바꿔 주는 도구입니다.
FreeCAD는 PC에 설치돼 있어야 하고, 화면 없는 FreeCAD(`freecadcmd.exe`)를 뒤에서 돌려서 변환합니다.

## 사용법

1. `stl2step.bat`를 받아서 바탕화면처럼 편한 곳에 둡니다. (처음 한 번만)
2. STL 파일을 `stl2step.bat` 아이콘 위로 끌어다 놓습니다. 여러 개를 한꺼번에 놓아도 됩니다.
3. STL이 있던 폴더에 같은 이름의 `.step` 파일이 생깁니다.

변환 중에는 진행 막대가 표시됩니다.

```
    [###############---------------]  52%  면 만드는 중 (4200 / 8414)  9초
```

- FreeCAD 위치는 자동으로 찾습니다. 못 찾으면 `stl2step.bat`를 메모장으로 열고
  `set "FC="` 줄에 `freecadcmd.exe` 경로를 적어 주세요.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르면 됩니다.
- 변환에 실패하면 `C:\Users\Public\stl2step\log.txt`에 원인이 기록됩니다.

## 자동 업데이트

실제 변환 로직은 `stl2step_core.py`에 있고, `stl2step.bat`는 실행할 때마다 이 파일의
최신 버전을 GitHub(이 저장소의 기본 브랜치)에서 받아 씁니다. 그래서 로직을 고칠 때는
GitHub에서 `stl2step_core.py`만 수정하면 되고, 배치 파일은 다시 받을 필요가 없습니다.

- GitHub의 캐시 때문에 수정 내용이 반영되기까지 몇 분 걸릴 수 있습니다.
- 인터넷이 안 되면 마지막으로 받아 둔 버전(`C:\Users\Public\stl2step\stl2step_core.py`)을 씁니다.
- 공개 저장소라서 누구나 코드를 볼 수는 있지만, 고칠 수 있는 건 저장소 주인뿐입니다.

## 변환 방식

STL은 삼각형만 있는 형식이라, FreeCAD 기본 방식("Create shape from mesh")으로 바꾸면
삼각형 하나하나가 STEP의 면이 됩니다. 이 도구는 그 대신 다음과 같이 변환합니다.

1. **같은 평면 묶기**: 이웃 삼각형 중 같은 평면에 놓인 것들을 한 덩어리로 묶습니다
   (기울기 차이 1° 이내, 평면에서 벗어난 거리가 모델 크기의 0.0002% 이내).
2. **점 정리**: 묶인 평면 위로 점을 정확히 옮기고, 두 평면이 만나는 직선 위에 있는
   쓸데없는 중간 점은 지웁니다. 한 점이 여러 평면 위에 동시에 놓일 수 없으면
   (곡면 쪽의 작은 평면이 끼어 있는 경우 등) 그 작은 묶음은 원래 삼각형으로 되돌립니다.
3. **면 만들기**: 평면 묶음 하나를 면 하나로 만듭니다. 처음부터 면끼리 모서리를 공유하게
   만들어서, 시간이 오래 걸리는 "꿰매기(sewing)" 과정이 필요 없습니다.
4. **검증**: 솔리드로 만든 뒤 유효한지, 원본 메쉬와 부피가 0.5% 이내로 같은지 확인합니다.
   문제가 있으면 자동으로 FreeCAD 기본 방식으로 다시 변환합니다.

그래서 FreeCAD에서 "Refine shape"(평면 합치기)를 한 것처럼 평평한 부분은 큰 면 하나가 되고,
속도는 그보다 훨씬 빠릅니다. 이 환경(리눅스, FreeCAD 1.0.2)에서 잰 결과는 다음과 같습니다.

| 시험 파일 | FreeCAD 방식 (형상 만들기 + 솔리드 + Refine + 저장) | 이 도구 |
|---|---|---|
| 기계 부품, 삼각형 3,370개 | 5.4초, 면 995개 | 1.9초, 면 996개 |
| 같은 부품을 곱게 나눈 것, 삼각형 33,334개 | 약 7.5분, 면 9,865개 | 34초, 면 8,414개 |

곡면(원통, 구, 필렛 등)은 여전히 잘게 나뉜 면으로 남습니다. 곡면을 진짜 원통면/구면으로
되살리는 기능은 아직 없습니다.

### 조절 값

`stl2step_core.py` 맨 위에서 바꿀 수 있습니다.

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `ANGLE_TOL_DEG` | `1.0` | 이웃 삼각형의 기울기 차이가 이 각도 이하일 때만 같은 평면 후보로 봄 |
| `DIST_TOL_REL` | `2e-6` | 평면에서 벗어난 거리 허용치 (모델 대각선 길이 대비 비율) |
| `VOLUME_TOL` | `0.005` | 결과 부피가 원본과 이 비율 넘게 다르면 기본 방식으로 전환 |
