# Gemini 이미지 생성 테스트 GUI

`gemini-image-generator` Rust 모듈(API 요청/응답 구조)을 실제 화면에서 손으로 눌러보면서 테스트하기 위한 아주 간단한 윈도우 프로그램입니다. PowerShell + WinForms로 만들어서 **설치 없이** 윈도우에서 바로 실행됩니다 (이 리포에 있는 다른 도구들과 같은 방식).

## 실행 방법

1. 이 리포를 본인 컴퓨터에 `git pull`
2. `gemini-image-test-ui` 폴더의 `run.bat` 더블클릭

관리자 권한 필요 없습니다.

## 기능

- **API 키 입력** — 입력하면 `%APPDATA%\GeminiImageTest\config.json`에 자동 저장되고, 다음에 켤 때 그대로 불러옵니다. 수정하면 수정한 값으로 다시 저장됩니다. (평문 저장이라 공용 PC에서는 주의하세요.) 바로 아래에 "Get an API key (Google AI Studio)" 링크가 있어서 클릭하면 발급 페이지가 브라우저로 바로 열립니다.
- **프롬프트 입력**
- **출력 폴더 선택** — "Browse..." 버튼으로 원하는 폴더를 고를 수 있고, 이것도 선택한 대로 저장/불러오기됩니다. 기본값은 `내 사진\GeminiImageTest`.
- **이미지 개수** — 1~20장, 기본 10장. 한 번에 여러 장 요청하는 API 파라미터가 따로 있는지 불확실해서, 안전하게 프롬프트 그대로 N번 반복 요청하는 방식으로 만들었습니다.
- **종횡비**: 1:1 / 16:9 / 9:16 / 4:3 / 3:4
- **해상도**: 1K / 2K / 4K
- **모델** — 시작할 때 API 키가 저장돼 있으면 자동으로, 또는 "Refresh list" 버튼을 누르면 Gemini의 ListModels API를 직접 조회해서 **이 키로 실제 쓸 수 있는 이미지 모델 목록으로 드롭다운을 갱신**합니다. 하드코딩된 두 모델(`gemini-3.1-flash-image`, `gemini-3.1-flash-lite-image`)은 조회 실패 시(키 없음/네트워크 오류 등)에만 기본값으로 남아있습니다. Google이 모델을 새로 내놓거나 정리해도 코드를 안 고쳐도 됩니다.
- **예상 비용 표시** — 모델/해상도/이미지 개수를 바꿀 때마다 장당 예상 가격과 이번 배치 총 예상 가격을 USD/KRW로 같이 보여줍니다 (모델 드롭다운 바로 아래 회색 글씨). 아래 "예상 비용은 어떻게 계산되나요" 항목 참고.

생성된 이미지는 선택한 출력 폴더 아래 `<타임스탬프>\` 폴더에 `image-01.png`, `image-02.png` ... 형식으로 저장되고, 다 끝나면 그 폴더가 자동으로 열립니다. 한 장이 실패해도(안전필터 차단 등) 나머지는 계속 진행하고, 로그 창에 몇 번째가 왜 실패했는지 표시됩니다.

## 검증 관련 참고

이 도구는 이 리포(원격 샌드박스)에서 만들었는데, 이 환경엔 PowerShell 실행 환경 자체가 없어서(리눅스) 실제로 띄워서 눌러보는 검증은 못 했습니다. 코드를 여러 번 읽으면서 확인했고, 그 과정에서 PowerShell의 잘 알려진 함정 하나를 미리 잡았습니다: `ConvertTo-Json`은 요소가 1개인 배열을 자동으로 벗겨버려서(`"contents": [{...}]`가 `"contents": {...}`가 되어버림) API 요청이 깨질 뻔했는데, 이 부분은 JSON을 직접 문자열로 조립하는 방식으로 피해갔습니다.

모델 목록을 필터링하는 기준(`generateContent`를 지원하고 모델 이름에 "image"가 들어가는 모델)은 공식 ListModels 응답 스키마에 "이건 이미지 생성 모델이다" 같은 명시적 플래그가 없어서 이름 규칙에 기대는 방식입니다 — 지금까지 나온 제미나이 이미지 모델은 전부 이름에 "image"가 들어가서(`gemini-3.1-flash-image` 등) 실용적으로는 맞지만, 나중에 구글이 이름 규칙을 바꾸면 깨질 수 있는 가정입니다. 그래도 실제 윈도우 환경에서 처음 실행할 때 한 번은 직접 확인해봐 주세요.

## 예상 비용은 어떻게 계산되나요

프로그램 안에 모델/해상도별 장당 가격표를 하드코딩해뒀습니다 (2026-07 기준 공식 가격 문서 확인):

| 모델 | 1K | 2K | 4K |
|---|---|---|---|
| gemini-2.5-flash-image | $0.039 (해상도 무관) | | |
| gemini-3.1-flash-image / -preview | $0.067 | $0.101 | $0.151 |
| gemini-3.1-flash-lite-image | $0.034 | (가격 미확인, 근사치로 표시) | |
| gemini-3-pro-image / -preview | $0.134 | $0.134 | $0.24 |

**주의할 점:**
- 구글 API 자체에는 가격을 조회하는 엔드포인트가 없어서, 이건 제가 손으로 넣어둔 값입니다. 시간이 지나면 실제 가격과 달라질 수 있어요 (공식: https://ai.google.dev/gemini-api/docs/pricing 에서 재확인 가능).
- USD → KRW 환율도 2026년 7월 기준 대략치(1,550원)로 고정해둔 것이라 실제 카드 결제 환율과는 다릅니다.
- 목록에 없는 새 모델이 뜨면 "unknown for this model"로 표시됩니다 — 가격표에 없는 모델이라 견적을 못 낸다는 뜻이지, 생성이 안 된다는 뜻은 아닙니다.
- **실제 청구 금액의 근거는 이 프로그램이 아니라 Google Cloud 결제 페이지입니다.** 어디까지나 참고용 견적이에요.

## Gemini API 키는 어디서 받나요

**Google AI Studio**에서 발급받습니다: https://aistudio.google.com/app/apikey

1. 구글 계정으로 로그인
2. 왼쪽 메뉴에서 "Get API key" 클릭
3. "Create API key" 클릭하면 키 문자열이 생성됨 (`AIza...`로 시작)
4. 그 문자열을 이 프로그램의 API Key 칸에 붙여넣기

무료 티어에도 요청 횟수 제한이 있으니, 10장을 한 번에 요청하면 중간에 rate limit(429)로 몇 개는 실패할 수도 있습니다 — 그것도 로그에 그대로 표시됩니다. API 키는 절대 다른 사람과 공유하거나 공개 저장소에 커밋하지 마세요.
