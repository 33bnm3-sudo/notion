# 썸네일 크롭

이미지를 아이콘 위로 **끌어다 놓으면** 에디터가 바로 열리는 작은 프로그램입니다. 자동으로 자르지 않아서 **어디를 얼마나 자를지 마우스로 직접** 정할 수 있습니다. 썸네일로 쓰기 좋게 밝기, 대비, 채도, 선명도 같은 **보정**도 할 수 있습니다.

- **따로 설치할 게 없습니다.** 모든 Windows 10/11에 기본으로 들어있는 C# 컴파일러(.NET Framework 4)로 처음 한 번 `ThumbCrop.exe`를 만들어서 씁니다. 파이썬, Node, 무거운 프레임워크는 필요 없습니다.
- 결과물은 `ThumbCrop.exe` 파일 하나(수십 KB)이고 실행이 바로 됩니다.

## 처음 한 번만: 바로가기 만들기

1. `install-shortcut.bat` 더블클릭
2. 프로그램이 자동으로 빌드되고, 아래 두 곳에 **"썸네일 크롭"** 바로가기가 생깁니다
   - **바탕화면**: 이미지 파일을 이 아이콘 위로 끌어다 놓으면 에디터가 열립니다
   - **보내기 메뉴**: 탐색기에서 이미지 우클릭 → (Windows 11은 "추가 옵션 표시") → 보내기 → 썸네일 크롭

바로가기 없이 이 폴더의 `run.bat` 위로 이미지를 끌어다 놓아도 똑같이 열립니다.

## 쓰는 방법

**자르기**
- 처음 열면 고른 비율로 가장 크게 잡힌 영역이 가운데에 있습니다
- 영역 **안에서 드래그**: 위치 이동
- **모서리/변 드래그**: 크기 조절 (비율 고정이면 비율 유지)
- 영역 **바깥에서 드래그**: 새로 그리기
- **마우스 휠**: 영역 크기 키우기/줄이기 · **방향키**: 1px 이동 (Shift 누르면 10px)
- **더블클릭** 또는 [최대 크기]: 비율에 맞는 가장 큰 영역으로
- 비율: `1:1`(기본), `16:9`(유튜브 썸네일), `4:3`, `3:4`, `9:16`(쇼츠/릴스), `자유`
- 사진이 누워 있으면 [왼쪽 90°]/[오른쪽 90°]. 휴대폰 사진의 회전 정보(EXIF)는 자동으로 반영됩니다

**보정** (썸네일이 잘 보이게)
| 항목 | 하는 일 |
|---|---|
| 밝기 | 중간 밝기를 올리거나 내림 (밝은 곳이 하얗게 날아가지 않는 방식) |
| 대비 | 밝은 곳은 더 밝게, 어두운 곳은 더 어둡게 |
| 어두운 부분 살리기 | 역광 등으로 시커먼 부분만 밝게 |
| 채도 | 색을 진하게/연하게 (-100이면 흑백) |
| 색온도 | 왼쪽은 차갑게(파랗게), 오른쪽은 따뜻하게(노랗게) |
| 선명하게 | 경계를 또렷하게 (작게 줄인 썸네일에 효과가 큼) |
| 자동 레벨 | 뿌옇고 흐릿한 사진의 가장 어두운 곳/밝은 곳을 펼쳐줌 |

- **✨ 자동 보정**: 선택한 영역을 분석해서 위 값들을 썸네일용으로 알아서 맞춰줍니다. 그다음 슬라이더로 조금씩 손보면 편합니다
- **원본 비교** 버튼을 누르고 있거나 캔버스에서 **마우스 오른쪽 버튼을 누르고 있으면** 보정 전 모습이 보입니다
- 슬라이더 옆 숫자를 클릭하면 그 항목만 0으로, [초기화]는 전부 0으로

**저장**
- 크기: `원본 해상도 그대로` 또는 `긴 변 1920 / 1280 / 1080 / 720 / 512 / 320px`
  - 예) 16:9 + 1280 → 1280×720, 1:1 + 1080 → 1080×1080
  - 고른 영역이 목표보다 작으면 "⚠ 확대됨"이 표시됩니다 (조금 흐려질 수 있음)
- 형식: JPG(품질 95%) 또는 PNG(무손실)
- **저장(Ctrl+S)**: 원본과 같은 폴더에 `원본이름_thumb.jpg`로 저장. 이미 있으면 `_thumb2`, `_thumb3`… 으로 덮어쓰지 않습니다
- **다른 이름…(Ctrl+Shift+S)**: 위치와 이름을 직접 고르기
- 저장 후 나오는 "폴더 열기"를 누르면 탐색기에서 결과 파일이 선택된 채로 열립니다

**여러 장 한꺼번에**
- 이미지 여러 장(또는 폴더)을 한 번에 끌어다 놓으면 [◀ 이전] [다음 ▶] (또는 PageUp/PageDown)으로 넘기면서 작업할 수 있습니다
- 다음 장으로 넘어가도 **보정 값은 그대로** 유지돼서 썸네일들의 톤을 맞추기 쉽습니다

비율, 저장 크기, 형식은 마지막에 쓴 값이 기억됩니다 (`%APPDATA%\ThumbCrop\settings.txt`).

## 지원 형식

- JPG, PNG, BMP, GIF, TIFF: 항상 열립니다
- WebP, HEIC, AVIF: Windows에 해당 코덱(Microsoft Store의 "WebP 이미지 확장", "HEIF 이미지 확장" 등)이 있으면 열립니다. 없으면 안내 메시지가 뜹니다
- 투명한 PNG를 JPG로 저장하면 투명한 부분은 흰색이 됩니다 (투명도를 살리려면 PNG로 저장)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `ThumbCrop.cs` | 프로그램 소스 전체 (C# / WinForms) |
| `build.bat` | `ThumbCrop.cs` → `ThumbCrop.exe` 빌드 |
| `run.bat` | 이미지를 끌어다 놓는 곳. exe가 없거나 소스가 더 새로우면 자동으로 빌드부터 함 |
| `install-shortcut.bat` / `Install-Shortcut.ps1` | 바탕화면/보내기 메뉴 바로가기 만들기 |

`ThumbCrop.exe`는 각자 컴퓨터에서 만들어지는 파일이라 저장소에는 올리지 않습니다(`.gitignore`). `git pull`로 소스가 바뀌면 `run.bat`이 알아서 다시 빌드하고, 바로가기로만 쓰는 경우엔 `build.bat`을 한 번 더블클릭하면 됩니다.

## 검증 관련 참고

이 환경은 리눅스 샌드박스라서, Windows 대신 **Mono(리눅스용 .NET)로 같은 소스를 C# 5 문법 제한을 걸고 컴파일**해서 가상 화면에 실제로 띄워 마우스/키보드로 조작하며 확인했습니다.

- 영역 이동/모서리 드래그/휠/비율 전환이 계산대로 동작하는지 숫자로 확인 (예: 1:1 826×826 → 16:9로 바꾸면 넓이 유지해서 1101×619)
- 16:9 + 긴 변 1280 저장 → 정확히 1280×720 JPG 생성, 화면 미리보기와 결과물이 같은지 확인
- 자동 보정, 여러 장 넘기기(이미지 아닌 파일은 자동 제외), 설정 기억, EXIF 회전(600×400 → 400×600), 투명 PNG → JPG 흰 배경 확인

다만 **Windows의 실제 화면(버튼 모양, 글꼴, 고해상도 화면 배율)과 `build.bat`/바로가기 생성은 직접 돌려보지 못했습니다.** 처음 쓰실 때 한 번 확인해 주세요. 빌드가 안 되거나 화면이 이상하면 그 화면/메시지를 알려주시면 고치겠습니다.
