# 바탕화면 검정 화면 복구 도구

탐색기(`explorer.exe`)를 재시작한 뒤 바탕화면이 검정색으로 멈춰 있을 때, 현재 설정된 배경화면을 강제로 다시 적용해주는 도구입니다.

## 사용 방법

1. `실행.bat`을 더블클릭합니다.
2. 레지스트리에 저장된 현재 배경화면 경로를 읽어와 다시 적용하고, Windows에 변경 사항을 알립니다.
3. 그래도 검정 화면이 풀리지 않으면:
   - 작업 관리자(`Ctrl+Shift+Esc`) → `Windows 탐색기` 우클릭 → 다시 시작
   - 또는 PC 재부팅

## 원리

- `HKCU\Control Panel\Desktop\Wallpaper` 레지스트리 값에서 현재 배경화면 경로를 읽습니다.
- `user32.dll`의 `SystemParametersInfo` API로 배경화면을 강제로 다시 그립니다.
- `UpdatePerUserSystemParameters`를 호출해 테마/배경화면 관련 설정을 전체적으로 다시 로드시킵니다.

시스템 파일을 수정하지 않으며, 현재 로그인한 사용자 설정만 다시 적용하는 안전한 도구입니다.
